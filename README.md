## ✨ 这个 Skill 能做什么

把你最爱的小说（txt 格式）喂给它，它会：

1. **拆解出每一个角色**——外貌、性格、口头禅、人际关系，比你自己还了解 ta。
2. **还原所有故事线**——不遗漏任何一章，不改编任何一句原著。  
   吴邪看到的，你以吴邪之眼看；  
   张起灵沉默的，你以张起灵之心听。
3. **让你随时“住进去”**——  
   用 `/change 张起灵`，下一秒你就是闷油瓶。  
   用 `/change 第三视角`，飘在空中看所有人。
4. **记住你在这个角色身上走到哪了**——  
   切回吴邪时，继续你上次的盗墓路；  
   切到小哥时，从头经历他的百年孤独。  
   **同一个时间点，不同的人生，不冲突。**

---

## 🎬 导演模式 · 绝不魔改

它不是一个“写同人小说”的 AI。  
它是一个**忠实的复刻引擎**。

- 剧情推进**完全按原著顺序**，不会让张起灵提前剧透。
- 你只能体验原著里发生的事，不能命令吴邪“别去鲁王宫”。
- 但你可以**选择关注什么**——当众人惊呼时，你可以盯着角落里的闷油瓶，看他有没有皱眉。

**原著是铁轨，你是列车长，但不是司机。**  
你只能选择坐在哪节车厢，看哪一侧的风景。

---

## 🕹️ 怎么玩

1. 把小说传给 AI（最好是分好章节的 .txt），同时输入：`使用穿越技能解析这本小说`
2. 等它拆完，输入 `/change 你想成为谁`
3. 系统会自动推给你**当前角色当前时刻**正在经历的情节
4. 你可以：
   - 回复“继续” → 剧情推进
   - 回复“我在想什么” → 系统告诉你这个角色的内心独白（基于原文）

**切角色之前，你的进度会被封存。**  
下次回来，一切如昨。

## 🧪 示例对话

> 你：`/change 张起灵`  
> 系统：你变成了张起灵。现在是《盗墓笔记》第一章，你混在三叔的队伍里，所有人都不认识你。吴邪正紧张地问：“这棺材里到底是什么？”  
> 你：继续  
> 系统：你瞥了一眼棺材缝，没有回答。原著里这时的你只是沉默。你选择：  
> 1. 继续保持沉默（原作向）  
> 2. 心里默念一句话（只有你自己知道）

> 你：`/change 吴邪`  
> 系统：你回到吴邪。上次你扮演他时，刚被吓得摔了一跤，现在屁股还疼。队伍准备下墓了。  
> 你：我偷偷看了一眼张起灵  
> 系统：（原著没有这个描写，但角色设定里吴邪对张起灵有好奇）你看见他站在阴影里，像一把没出鞘的刀。心跳快了一拍。
